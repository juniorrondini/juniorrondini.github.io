# Project captures

These images are screenshots of the actual public websites, captured on 2026-11-11 at a 1280 × 960 viewport. They preserve the published interface. No generated artwork, compositing, recoloring, or invented UI was used.

- `genesys-desktop*.webp`: https://www.genesyssoft.com.br/
- `saude-desktop*.webp`: https://saudealimentar.vercel.app/

The captures were retrieved through WordPress mShots. The 768 px versions are proportional downscales; they are not mobile screenshots. Only encoding and proportional resizing were applied. Originals remain in the ignored local `.qa/` directory.

Projects without a verified interface capture remain in the text index. Do not add conceptual covers or unrelated images as replacements.
